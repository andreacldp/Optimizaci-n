# Reto: Pal Sur del Norte

Este proyecto implementa un modelo de Vehicle Routing Problem (VRP) utilizando programación lineal entera con PuLP para optimizar la distribución de despensas en comunidades del municipio de Mier y Noriega, Nuevo León. El modelo busca maximizar la atención a localidades con mayor vulnerabilidad social, considerando restricciones de capacidad del vehículo y costos de operación.
